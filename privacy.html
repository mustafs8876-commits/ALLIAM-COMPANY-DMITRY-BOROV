ИНФОРМАЦИЯ О ДАННЫХ

Конфиденциальность

Перед публичным запуском владелец сайта должен указать актуальное юридическое лицо / ФИО оператора данных, контактный e-mail, адрес (при необходимости), юрисдикцию и сроки хранения с учётом применимого законодательства. Эта страница — проект, не окончательная политика.

Какие данные получает сайт

При заполнении формы посетитель сам передаёт имя, выбранную тему, способ связи и описание обращения. Не указывайте пароли, реквизиты банковских карт и иные секреты.

Для чего нужны данные

Для рассмотрения обращения, связи с посетителем и обсуждения возможного формата помощи.

Как обрабатываются обращения

При настроенной отправке форма передаёт данные по защищённому соединению на серверную функцию Vercel и далее через Telegram Bot API в рабочий чат получателя заявки. Сайт не создаёт отдельную базу заявок. Доступ к сообщениям и их хранение зависят от настроек Telegram и администраторов чата. Если включена защита от спама, технические данные могут проверяться сервисами Cloudflare Turnstile и Upstash Redis (без сохранения текста заявки в Redis).

Ваши запросы

По вопросам доступа, исправления или удаления персональных данных обращайтесь по контактному адресу владельца сайта, который должен быть добавлен перед запуском.
